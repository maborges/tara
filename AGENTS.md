## Agent skills

### Issue tracker

Issues são gerenciadas no GitHub Issues usando a CLI `gh`. Veja `docs/agents/issue-tracker.md`.

### Triage labels

Usar os rótulos padrão: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human` e `wontfix`. Veja `docs/agents/triage-labels.md`.

### Domain docs

Layout multi-contexto, com `CONTEXT-MAP.md` na raiz e `CONTEXT.md` por contexto. Veja `docs/agents/domain.md`.
