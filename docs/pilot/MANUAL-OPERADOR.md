# Manual do Operador (Estação de Pesagem)

Bem-vindo à nova Plataforma Balança. O sistema funciona pelo navegador do computador.

## 1. Acesso (Login)
1. Abra o navegador (Google Chrome ou Edge) no atalho **"Balança"**.
2. Selecione seu nome de operador na lista.
3. Digite o seu **PIN numérico (senha)**.
4. *Nota: o login continuará funcionando mesmo se a internet do computador cair, desde que o acesso tenha sido feito pelo menos uma vez anteriormente.*

## 2. Selecionar uma Ordem de Pesagem
Quando um caminhão entra:
1. Clique em **"Nova Pesagem"** ou selecione uma ordem na lista de **Ordens Pendentes**.
2. Se a ordem veio do escritório, os dados (Placa, NF, Produto) já estarão na tela.

## 3. Pesagem Avulsa (Sem ordem)
Se não há ordem na lista:
1. Clique em **"Pesagem Avulsa"**.
2. Preencha manualmente a Placa e as informações exigidas.

## 4. Capturar Peso (Pesagem Única)
1. Certifique-se de que o caminhão está inteiro sobre a balança.
2. Observe o **Peso Atual** no topo da tela. 
3. Quando a luz indicar verde e a mensagem disser "Estável", clique no botão **"Capturar Peso"**.
4. O sistema registrará a pesagem eletronicamente.

## 5. Pesagem Dupla (Entrada e Saída)
1. **Primeira Passagem:** Escolha a ordem, capture o peso (ex: Bruto na entrada). O veículo fica com status "Pendente" (Dentro da planta).
2. **Segunda Passagem:** Quando o caminhão for sair para pesar novamente, encontre-o na lista de "Pendentes".
3. Capture o peso novamente (Tara).
4. O sistema mostrará as duas pesagens (Bruto e Tara) e calculará o **Peso Líquido** automaticamente. Confirme.

## 6. Operação Offline (Sem Internet)
Se a internet cair, o sistema **não trava**.
1. O aviso **"Offline"** vermelho aparecerá no topo.
2. Continue trabalhando normalmente (selecionar ordem, pesar avulso, capturar peso).
3. Todas as pesagens aparecerão na lista lateral de **"Pesagens Pendentes"**. 
4. Quando a internet voltar, a lista de pendentes sumirá sozinha enviando tudo ao escritório. Se não sumir, clique em **"Sincronizar"**.

## 7. Quando Chamar o Suporte?
Chame o suporte técnico se:
- O sistema não abrir (Página em branco).
- O Peso Atual na tela ficar vermelho avisando "Balança Desconectada" (e verificar o cabo da balança não resolveu).
- O aviso de "Pendentes" travar com muitas pesagens mesmo após a internet retornar.
